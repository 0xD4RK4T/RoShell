# RoShell
RoShell is command line tool that let you explore and manipulate the Roblox's process memory.

# Description
This program attaches himself to RobloxPlayerBeta.exe and interact with the internals objects of the game like it was a file system.
It has a terminal interface to navigate in DataModel, read and modify some values.

# Main functionalities
- Navigate in the instances
- Reading/saving game's scripts
- Injecting LUA code by modifying game's scripts
- Reading/writing to game's values (int, bool, float, ...)
- Directly writing and reading memory (not perfect)

# Disclamer
This project has been made for educational purposes only. It's not meant to take advantage on other players but lets you understand how the roblox's memory is working.
